# Перевірка валідації кінцевих точок

Негативні й позитивні перевірки всіх кінцевих точок ресурсу Organizations, виконані вручну через Swagger UI.
Цілі, яким вони відповідають, описані в [quality-attributes.md](quality-attributes.md); контракт — в [api-design.md](api-design.md).

### GET /api/v1/organizations

| ID   | Вхід               | Очікувано                                         | Факт                  |
| ---- | ------------------ | ------------------------------------------------- | --------------------- |
| V-01 | без параметрів     | `200`, `limit=20`, `offset=0`, `total`, `hasMore` | ✅                    |
| V-02 | `limit=0`          | `400`, `INVALID_PARAMETER`, поле `limit`          | ✅                    |
| V-03 | `limit=101`        | `400` (не обрізання до 100)                       | ✅                    |
| V-04 | `offset=-1`        | `400`, поле `offset`                              | ✅                    |
| V-05 | `q` зі 101 символу | `400`, поле `q`                                   | ✅                    |
| V-06 | `limit=abc`        | `400`, `INVALID_PARAMETER`                        | ✅                    |
| V-07 | `q=клуб`           | `200`, лише організації з «клуб» у назві або slug | ✅ (з URL-кодуванням) |
